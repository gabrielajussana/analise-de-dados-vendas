# 🧪 Análise de Dados de Vendas com Python

## 📋 Visão Geral

Este projeto foi desenvolvido com o objetivo de analisar dados de vendas em JSON e aplicar técnicas de qualidade de dados, explorando problemas e inconsistências que podem afetar relatórios e tomadas de decisão.


## 🎯 Objetivos
- Carregar e manipular dados JSON
- Transformar os dados em DataFrames (pandas)
- Detectar problemas e inconsistências
- Criar validações automatizadas
- Gerar análises e insights relevantes
- Produzir relatórios claros e úteis

## 📁 Estrutura do Projeto

```
avaliacaoQA/
├── desafio_qa_python.ipynb    # Jupyter Notebook principal
├── dados_vendas.json          # Dados de vendas

```
## 🚀 Tecnologias Utilizadas
- Python 3
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

## ⚙️ Como Executar

### Pré-requisitos
Instale as dependências do ambiente Python: 
```bash
# Instalar dependências
pip install pandas numpy jupyter matplotlib seaborn

# Ou usando conda
conda install pandas numpy jupyter matplotlib seaborn
```
### Passos
Clone o repositório:
```` bash
git clone https://github.com/gabrielajussana/analise-de-dados-vendas.git
````
Abra o Jupyter Notebook:
```` bash
jupyter notebook desafio_qa_python.ipynb
````
Execute as células e explore os resultados.

## 📊 Exemplos de Análises
Alguns exemplos implementados no notebook:
- Validação de preços negativos
- Agrupamento de vendas por categoria
- Detecção de inconsistências nos registros
- Visualizações gráficas de vendas
